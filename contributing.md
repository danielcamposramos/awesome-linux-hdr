# Contribution guidelines

Please open a pull request that adds or corrects one logical thing and explains
why it belongs.

## Scope

This list covers the Linux path required to create, decode, render, transport,
display, diagnose, or repair HDR and wide-colour output. Cross-platform
projects belong when their Linux implementation is relevant.

General photography, display shopping advice, AI HDR-image synthesis, and
title-by-title game compatibility lists belong in more specialized projects.

## Quality bar

- Prefer specifications, upstream source, maintainer documentation, and
  reproducible measurements over summaries.
- Label normative, implemented, measured, reported, and proposed evidence.
- Name hardware and software versions for measurements.
- Separate deep colour, wide gamut, transfer function, metadata, sink state,
  and measured light output.
- State missing hardware or incomplete validation explicitly.
- Link standards; do not upload copyrighted copies without redistribution
  permission.
- Use one entry per line: `[Name](URL) - Factual description.`
- Mark abandoned or version-limited projects honestly.

AI-assisted contributions are welcome when the submitter owns, understands,
and can defend the result. Record the assisting partners in the contribution's
provenance when their work materially shaped it.
